# 👨‍💻 Cake Ordering Web Application (Group Project)
**Cake ordering web application for a cake shop called as "Yummy Cake"**

---

## ✨ Features

- Customer interface
     - Create user accounts
     - Edit user account details with password changing
     - Search cakes by categories and subcategories
     - Search cakes by brands
     - Add cakes to the cart
     - Edit cart details
     - Place orders by filling relevant details
     - Find the cake shop location using the map

- Admin interface
     - Manage products
     - View orders
     - View revenue
     - Manage categories
     - Manage subcategories
     - Manage brands
     - Manage customers

---

## 💻 Tech Stack
- HTML
- CSS
- Bootstrap
- JavaScript
- PHP

---

## 🛠️ Development Tools
- Visual Studio Code
- XAMPP
